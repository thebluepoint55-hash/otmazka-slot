# Отмазино

Шуточный игровой автомат, который выдаёт отмазки для начальника. Вариант Б из [BRIEF.md](BRIEF.md), сделан для съёмки Reels.

## Как открыть

Дважды щёлкните `index.html`. Сборка и сервер не нужны. Интернет нужен только для шрифтов Google Fonts (Rubik Mono One и Rubik).

Основной экран для съёмки: 1440–1920 px по ширине, есть и мобильная версия (см. ниже). Размеры привязаны к высоте окна, поэтому кадр одинаковый на 1440×900 и 1920×1080. Всё главное держится в центральной колонке шириной 9:16 от высоты, под вертикальный кроп.

## Путь по экранам

1. **Главная.** Вывеска с бегущими лампочками и «битой» неоновой буквой, мини-барабаны, кнопка «Дёрнуть рычаг», по бокам ленты «Последние выигрыши» и «Что выпадает чаще».
2. **Оплата.** Пакеты жетонов. Тестовая карта `4242 4242 4242 4242` впечатывается сама; ничего не вводится, не собирается и никуда не отправляется. После «оплаты» монеты по дуге летят в монетоприёмник, счётчик щёлкает.
3. **Генератор.** Пять ситуаций, три 3D-барабана («кто / что случилось / итог»). Рычаг можно тянуть мышью или кликнуть, также работают кнопка «Крутить» и пробел. Первый прокрут всегда с «почти выигрышем», дальше примерно в 45% случаев. Затем «ДЖЕКПОТ!», дождь из монет, тряска и билет с отмазкой, который печатается из щели.
4. **Мессенджер.** «Отправить начальнику»: отмазка впечатывается и уходит, начальник «печатает…» и отвечает. Исход — честная монетка 50/50: отмазка либо прокатывает (ответ шефа, реакция 👍, зелёный штамп «ПРОКАТИЛО!»), либо нет (шеф сначала мнётся, потом пишет что-то неприятное, реакция 🤡, красный штамп «НЕ ПРОКАТИЛО» и грустный тромбон). На каждую ситуацию по 6 вариантов ответа на каждый исход, иногда шеф пишет два сообщения подряд.

## Музыка

Фоновая казино-музыка синтезируется в браузере, как и звуки: свинговый лаунж игрового зала на 132 удара в минуту. «Шагающий» бас, электропиано, щётки и тарелка ride, мелодия на вибрафоне и редкий перезвон автоматов вдали. Петля из 8 тактов. Музыка начинается с первым кликом или касанием (раньше браузер звук не разрешает) и приглушается на время джекпота и «грустного тромбона». Включена по умолчанию; выбор запоминается в браузере.

## Мобильная версия

На вертикальных экранах (телефоны, планшеты в портрете) колонка автомата занимает всю ширину, боковые панели убираются, а «Последние выигрыши» показываются бегущей строкой внизу главной. Мессенджер открывается на весь экран, без рамки телефона. Рычаг тянется пальцем. Долгое нажатие (около секунды) на логотип «ОТМАЗИНО» сбрасывает всё, как клавиша `R`.

На iPhone звук Web Audio не играет, если включён беззвучный режим (переключатель сбоку).

## Режиссёрские клавиши

| Клавиша | Что делает |
|---|---|
| `R` | Полный сброс: жетоны, история, билет; возврат на главную |
| `1` `2` `3` `4` | Главная / Оплата / Генератор / Мессенджер |
| `Пробел` / `Enter` | Главное действие экрана: рычаг, оплата, CTA |
| `M` | Весь звук вкл/выкл (кнопка с динамиком в правом верхнем углу) |
| `B` | Фоновая музыка вкл/выкл (кнопка ♫ рядом) |

Если сразу открыть генератор клавишей `3`, не покупая жетоны, автомат сам выдаст 5 жетонов.

## Устройство

- `js/data.js` — база: 5 ситуаций × 7 «кто» × 7 «что случилось» × 7 «итогов», плюс 4 вступления на ситуацию. Глаголы согласуются по роду через запись `{м|ж|мн}`.
- `js/engine.js` — общий цикл `requestAnimationFrame`, барабан-цилиндр (`rotateX` + `translateZ`) с физикой: замах, разгон, торможение со степенной кривой и пружинный отскок. Рычаг на пружине с упором.
- `js/audio.js` — все звуки и фоновая музыка синтезируются через Web Audio, без файлов.
- `js/app.js` — экраны, оплата, прокрут, билет, мессенджер, клавиши.

Анимируются только `transform` и `opacity`; вместо `blur` у барабанов отдельный слой «смаза», у которого меняется только прозрачность. При `prefers-reduced-motion` убраны тряска, дождь монет, «почти выигрыш» и бегущие огни; барабаны останавливаются быстрее.
